README

hosting & deploy notes

GitHub Pages setup, static-host requirements, how to read the map, and what each file in this folder is for.

Running the PWA locally. The web app fetches its data, which file:// blocks, so it needs a server: cd pwa && python3 -m http.server 8000 then open http://localhost:8000. Hosted, it just works — the included GitHub Actions workflow publishes pwa/ to Pages. If you only want to look at the map, use the standalone HTML above instead.

What you're looking at

Each point is one distinct alert — a unique combination of signature, category, protocol, target host, URI and destination port. Position comes from the semantic similarity of that text, so related attacks land together. Zooming reveals finer label layers. Clicking a point opens its details and a link to the Emerging Threats rule page for that signature.

  • wrccdc-2017 — 27,500
  • wrccdc-2018 — 27,500
  • first-org-2015 — 4,429
  • honeypot-2018 — 150

Sources are sampled deliberately, not proportionally — they differ in size by four orders of magnitude, so proportional sampling would have erased the honeypot entirely. Point density is not incidence rate; use the count field on a point's card for volume.
